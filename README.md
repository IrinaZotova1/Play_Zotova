# Игра Зотова Ирина 4-МД-5

# The Magician's Trial — Испытание мага

2D-платформер с элементами алхимии и битвой с боссом. Маг проходит 11 испытаний: 
от зелёных холмов до сердца горы, где его ждёт Горный Монстр.


### Требования
- Современный браузер (Chrome / Firefox / Edge / Safari), поддерживающий Canvas 2D и Web Audio API.
- Разрешение экрана не меньше 1280×720 (игра адаптируется, но рассчитана на 1280×720).
- Работает офлайн после первой загрузки шрифта Nunito (Google Fonts).

## 🎮 Управление

| `A` / `←` | Движение влево |

| `D` / `→` | Движение вправо |

| `W` / `↑` / `Space` | Прыжок (есть coyote-time и jump-buffer) |

| `Q` | **Земля** — создать каменный столб под собой (кулдаун 3 с) |

| `E` | **Огонь** — луч вперёд, наносит урон стражам и боссу (кулдаун 3.5 с) |

| `F` | **Вода** — ледяная платформа под ногами (кулдаун 4 с) |

| `T` | **Воздух** — восходящий поток, подбрасывает вверх (кулдаун 5 с) |

| `R` | **Ворон** — летит вперёд и приносит 3 звезды / бьёт босса (кулдаун 8 с) |

| `P` / `Esc` | Пауза |

| `Enter` | Перезапуск уровня после поражения |



 🧪 Механики

- **11 уровней** с уникальной темой: земля, огонь, вода, воздух, кристаллы, руины.
- **Две параллельные тропы** на большинстве уровней: безопасная (внизу) и рискованная (вверху).
- **Магазин** — 14 предметов наряда (шляпы, мантии, посохи) за звёзды.
- **Алхимия** — 6 ингредиентов × 15 рецептов → 15 уникальных субстанций.
- **Ворон-помощник** — бонусные звёзды или помощь в бою с боссом.
- **Босс** — Горный Монстр (15 HP), атакует камнями и ударными волнами.
- **Сохраняется автоматически** в `localStorage` (прогресс, наряд, рецепты, звук).



 🔊 Звук

Звук можно полностью отключить:
- В игре: главное меню → `⚙ Настройки` → переключатель `🔊 Звуки`.
- Настройка сохраняется в `localStorage` и применяется при следующем запуске.
- Весь звук — процедурный, синтезируется через Web Audio API (`OscillatorNode`).
- Никаких аудиофайлов не загружается и не воспроизводится.



 🎨 Графика и звук — источники и лицензии

Графика
Внешних изображений нет. Вся графика (маг, платформы, босс, ворон, монеты, 
эффекты, UI-иконки) нарисована кодом на Canvas 2D через стандартные 
API: `fillRect`, `arc`, `quadraticCurveTo`, `createLinearGradient`, 
`createRadialGradient`, `ellipse`, `bezierCurveTo`.

- Лицензия: CC0 / Public Domain — код игры можно использовать свободно.
- Иконки элементов (⛰ 🔥 💧 💨 ✦ ☠) — стандартные Unicode-эмодзи, 
  предоставляются операционной системой / шрифтом браузера.

Звук
Аудиофайлов нет. Все звуки синтезируются в реальном времени 
через Web Audio API (осцилляторы + огибающая gain).

- Отключается в настройках игры (см. раздел «Звук»).

Шрифт
Nunito (Google Fonts) 


Что не используется
- Внешние PNG / JPG / SVG / GIF
- Внешние MP3 / WAV / OGG
- Сторонние игровые движки (Unity, Godot, Phaser, PixiJS)
- Сторонние CSS-фреймворки (Bootstrap, Tailwind)
- Трекеры, аналитика, cookies

 
 🐛 Известные особенности

- На iOS Safari звук может не запуститься до первого касания экрана — это 
  ограничение политики автовоспроизведения Apple. Любой клик/тап в меню 
  разблокирует звук.
- При открытии через `file://` в Safari прогресс может не сохраняться — 
  используйте локальный HTTP-сервер (см. раздел «Запуск»).
- Если игра «дёргается», проверьте, включено ли аппаратное ускорение в браузере.



 🎯 Советы

- Верхний путь опаснее, но даёт больше звёзд — пригодится в магазине.
- Огонь (`E`) — единственный способ убить стражей без потери здоровья.
- Воздух (`T`) можно использовать как двойной прыжок в воздухе.
- На боссе ворон (`R`) наносит сразу 3 урона и оглушает на 1.5 с.
- При падении в пропасть вы теряете 1 HP и возрождаетесь на последней 
  безопасной платформе.
